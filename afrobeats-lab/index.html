What actually makes an Afrobeats hit? Spotify audio features, Pandas analysis and two scikit-learn models, running live in your browser.

No data yet

The dashboard reads afrobeats-lab/data/insights.json, which the Python pipeline generates.

  1. Download the free Spotify Tracks Dataset (maharshipandya) CSV from Kaggle or Hugging Face.
  2. Save it as afrobeats-lab/pipeline/data/dataset.csv.
  3. Download the modern Afrobeats data, beatsofafro.csv, and save it next to it.
  4. Run:
    cd afrobeats-lab/pipeline
pip install -r requirements.txt
python analyze.py data/dataset.csv --afrobeats data/beatsofafro.csv
  5. Commit the new data/insights.json and push.
